# Mail Box

This is the DSA Visualized mentor's inbox for cross-project mail — other projects' co-founder mentors drop files here to share information relevant to this project.

- **File naming:** `<Topic Name>.md` (whatever the sender names it).
- **Read at the start of every session** (`@skills/skillCoFounderMentor.md`): each file is read in full, anything valuable is folded into `co-founder/state.md`, `co-founder/roadmap.md`, `co-founder/notes.md`, or `CLAUDE.md` as appropriate, and the mail file is then **deleted** — this folder is an inbox, not an archive.
- Outbound mail (this project sending mail to *other* projects) is a separate flow — see `co-founder/mail-recipients.md` and the "Mail Box" section of `skills/skillCoFounderMentor.md`.

This file (`README.md`) is the only thing in this folder that should survive — it's not a mail file and won't be deleted during inbox processing.
